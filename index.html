About

I build LLM agents and the layers that make them dependable. In 2026 I designed a policy layer that checks every tool call an agent proposes just before it runs, using only conditions the conversation record can settle. With no extra training it raised an open 27B model's τ³-bench banking pass^1 from 49.5 to 57.2 (board leader: 55.2), and it moved to new benchmarks by swapping the declaration file while the engine code stayed the same.

Before that, at Nethru, I designed and built a behavior-data prediction and recommendation platform for financial clients and a marketing-analysis agent PoC for Woori Bank, demonstrated to the bank's CEO. Earlier I led an AI development division (industry–academia research with POSTECH, KAIST and Asan Medical Center; national R&D programs) and, for 15 years, mobile, set-top and network-equipment software development.

Highlights

Policy Harness — a deterministic policy layer for LLM agents

Independent research, 2026 · two provisional patent applications filed

The layer sits between the model's proposed call and the real tool. It blocks only on conditions the transcript settles (a required lookup was done, a value appears in a tool output or the customer's words, a computation matches the record) and returns the unverified fact and the policy sentence so the model decides again. The rule engine gives the same verdict for the same input and keeps an audit log.
